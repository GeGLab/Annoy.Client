Provider marks are brand assets, preserved independently of Annoy's theme palette.

- Spotify: official green RGB icon from https://developer.spotify.com/images/guidelines/design/2024-spotify-logo-icon.zip. Guidelines: https://developer.spotify.com/documentation/design.
- Steam: Steam mark from the Simple Icons project (CC0 library), https://github.com/simple-icons/simple-icons/blob/develop/icons/steam.svg. The underlying mark belongs to Valve.
- Apple Music: music-note mark from Simple Icons, https://github.com/simple-icons/simple-icons/blob/develop/icons/applemusic.svg, shown in its brand color. The underlying mark belongs to Apple.
- Editor and language marks: Devicon, https://github.com/devicons/devicon (MIT; see devicon-LICENSE). Product marks remain the property of their respective owners.

# Local file-type glyphs

`json.svg` is an original JSON brace glyph drawn for the activity preview. It
uses the surrounding card's file name as its accessible description.
