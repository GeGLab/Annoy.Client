# Desktop conversations

Mode: Operate. Code-first implementation, explicitly chosen by the user.

Pinned direction: the supplied Discord-like desktop references take precedence over the direction seed. Navigation and interactions remain familiar; no borrowed Discord mark or blurple palette.

The user requested retaining the collaborator's upstream Annoy 0.3.1 rename and identity while integrating these features. Preserve its speech/robot silhouette as one filled symbol with transparent negative-space eyes and alert marks, without a white tile. The renderer uses the semantic theme accent; packaged icons use amber. Preserve the amber on indigo graphite palette; the light counterpart remains warm ivory with a readable amber accent. Keep the calm compact navigation, generous conversational space and short reduced-motion-aware reveal when opening an image. The earlier speech/D mark and tangerine palette are superseded by the upstream identity, not proposed as a competing brand.

The split-flap challenger donates stable alignment, the record-catalog challenger donates disciplined whitespace, the map challenger donates a single color for selection, and the boarding-pass challenger donates clear state hierarchy. Their literal forms would obscure community conversation, so they are declined under the user's familiar-desktop constraint. No competing topology is introduced.

First viewport: a draggable application titlebar; persistent server rail; channel/DM sidebar with voice and profile controls; a flexible conversation area; members on server channels. First run has real connection actions and an honest empty conversation state. No synthetic content ships.

Quality bar: visible focus, 4.5:1 body contrast, consistent 36px action targets, 8px control radius, 160–200ms state transitions, reduced motion, dark/light tokens, keyboard-dismissable focus-trapped dialogs, and no overflow at the 940px minimum desktop width.

Refinement: the first rail action opens direct messages. Keep the compact side
rail free of duplicate Home labels and idle recent-DM shortcuts; tooltips and
accessible names identify unread DMs and server/service tiles. The dashed plus and visible Nova aba caption follow the last server/service
tile inside navigation; only news remains in the footer. This supersedes labeled shortcut/server groups.
Shared emoji/count reaction chips sit below message attachments; clicking joins
or leaves the same emoji, while quick actions and the picker add reactions.
Channels stay open,
members toggle from one header action, and both widths remain adjustable. Voice
shows connection, channel/server, participants, camera/sharing and device menus.
Shared portal menus animate both entering and leaving. Image wheel zoom and
lazy audio/video players keep attachments inside the app. Personal colors have
a HEX/palette picker and recent history. Settings use drafts, a floating save
bar and guarded dismissal/navigation. Profile editing previews the unsaved display name, staged photo (including
animated GIFs) and biography in public-profile markup with the actual 35% rounded
avatar mask and three-line biography clamp. Uploads/removal and public changes
wait for explicit Save. Global authentication has its own Conta global category,
stacked email/password inputs and a separate registration link to the external
global portal.

Media refinement: the conversation picker keeps only Emojis, GIFs and Figurinhas,
with Gerenciar linking to Configurações → Emojis e mídia. Installation, import,
export, removal and collapsed GIPHY configuration belong to settings. Usar returns
to an active conversation without losing its draft or bypassing save/discard
guards. The reaction menu starts with 16 common emojis and exposes catalog search
and expansion. Preserve compact dark/light layouts at the 940px desktop minimum.

Discovery and privacy extension: titlebar search (Ctrl+K) opens a protected,
filterable message search with context jump and a clear return-to-latest action.
Permission targets use a grouped searchable picker with role identity, member
avatar/username and explicit customized-permission state. Form controls and
confirmations share Radix/shadcn-style primitives. Friend activity is a compact
sidebar section and profile detail, never public member metadata. Settings
explain opt-in game/music sharing and its friends-only audience.

Installed media packs expose Usar to open the matching local emoji/GIF/sticker
tab. Selection prepares a composer attachment; Send remains explicit. When the
connected Server lacks reactions support, Add reaction explains the required
Server update and Client reconnection. Updating only the Client does not make
reactions shared.
