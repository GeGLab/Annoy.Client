# Annoy 0.12.0-alpha.2

- Fixed the account panel showing a different name or losing the avatar when switching between Friends, DMs, linked communities and settings. These views now use the same Annoy profile.
- Fixed integration requests failing with “The integration did not respond” because public IPv4 addresses were incorrectly blocked. Signature headers now reach the integration service.
- DMs show when an integration is waiting for the other person to accept. Calling it while pending also displays a notice. Pending requests can be accepted or declined from the conversation's integrations dialog.
- In servers and communities, the owner decides which integrations are installed. Members do not need to accept them individually; the existing Use integrations permission applies.

Windows: `Annoy-Setup-x64.exe`. Linux: `Annoy-x86_64.AppImage`. Signed automatic updates are included.

Integration calls made by a server need Annoy Server `0.12.0-alpha.2` for the IPv4 fix.
