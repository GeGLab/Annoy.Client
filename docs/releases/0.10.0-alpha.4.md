# Annoy 0.10.0-alpha.4

## Fixes
- Joining voice no longer fails with an empty "Voice:" message when the microphone chosen in the settings is not connected. The app uses the system default microphone and lets you know.
- Microphone errors say what went wrong: access denied, no microphone found, or microphone in use by another program.

- The News screen shows this version's changes.
