# Annoy 0.12.0-alpha.3

- Type `/` to preview the commands available in the current conversation. Suggestions include the integration, description and argument syntax; Steam's `profile` and `versus` appear separately.
- Use the arrow keys to navigate and Tab, Enter or a click to fill the command. Choosing a command never sends the message. Escape closes the list, and the usage hint stays visible while entering arguments.
- Server suggestions follow installed integrations and the member's Use integrations permission. DMs show integrations accepted in that conversation.
- Integration images can use up to 960 pixels of conversation width. Large comparison cards remain readable and open in the image viewer.
- SteamProfiler's `/steam versus` now returns a large visual comparison with both profiles, ownership overlap, and six shared games with individual playtime. Ownership includes games not yet played. This card is provided by the updated SteamProfiler service.

Windows: `Annoy-Setup-x64.exe`. Linux: `Annoy-x86_64.AppImage`. Signed automatic updates are included. Annoy Server `0.12.0-alpha.2` remains compatible.
