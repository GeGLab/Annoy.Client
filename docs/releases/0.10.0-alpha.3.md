# Annoy 0.10.0-alpha.3

Mandatory update.

## Fixes
- Your Annoy account's servers come back. Accounts moved to the new account service kept an old "migration pending" mark that made the app skip server sync without a word.
- Servers follow your account on every device: adding or removing a server on one device changes the others at once.
