# Annoy 0.13.2-alpha.1

## One profile, one place
- The profile (name, photo, bio and @username) of an Annoy account is read only from the Annoy account (usersannoy), by Annoy ID, on every server, in DMs and in the own-user panel. Servers no longer keep or send a copy, and the app no longer copies the profile into them.
- A minimal local cache keeps the last answer for each person; every change updates it, and it is read only while the Annoy cloud does not answer at all.
- Local-mode servers (accounts without Annoy) keep their own profile, sent separately from the user.
- Joining a server with the Annoy account no longer asks for a server username; invite-only servers ask only for the invite.
- Integrations receive people by Annoy ID; GPT reads names by ID.

Requires Annoy Server 0.13.2-alpha.1, which also requires this app version or newer.
