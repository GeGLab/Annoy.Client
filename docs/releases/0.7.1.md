## Annoy 0.7.1

- **Atualizar o servidor pelo app:** em Administrar instância → Atualizações, o admin vê a versão instalada e a mais nova, clica em **Atualizar agora** e escolhe se as atualizações são automáticas.

Precisa do servidor na 0.7.1 (uma vez: `git pull && docker compose up -d` na pasta do annoy-server).

Windows: `Annoy-Setup-x64.exe`. Linux: `Annoy-x86_64.AppImage`. Quem já tem o app recebe a atualização sozinho.
