# Annoy 0.10.0-alpha.6

## Fixes
- Updating to 0.10.0-alpha.5 reset the settings (devices, noise filter, microphone filters, volumes, app icon, panel sizes): the store read them before the old `distopic.*` keys were moved to `annoy.*`. The move now runs first. Installs still on 0.10.0-alpha.4 keep their settings; settings already reset by 0.10.0-alpha.5 cannot be restored by the app.
- New Annoy stickers and emojis added in admannoy show as soon as the picker opens (the app checks the set each time, with a 304 when nothing changed), instead of up to 2 hours later.

## Also in this version
- The News screen shows this version's changes.
