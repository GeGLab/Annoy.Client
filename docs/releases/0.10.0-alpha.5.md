# Annoy 0.10.0-alpha.5

Needs annoy-server 0.10.0-alpha.5 and the Annoy cloud from the same date for the account changes.

## One profile
- Name, photo and bio live in the Annoy account. DMs and every server show the same profile; the app copies it to each server signed in with the Annoy account. Empty Annoy profile fields are filled once from the server profile.
- Profile contacts (with who sees them), activity history and Steam live in the Annoy account. "Friends and communities in common" checks the servers you share through the Annoy Global.
- User settings show only the Annoy account. Servers signed in with it no longer appear there; leaving is "Leave server" in the server menu. Local accounts show only "Delete account", with a second confirmation.

## Leaving and deleting
- Leaving a server keeps your messages there, with the author "Unknown user".
- "Delete account" opens the Annoy web dashboard. Deleting removes everything of the account: profile, friends, DMs, files, Steam, history; you leave every server and your messages stay as "Unknown user". Servers where you are the only member are deleted; servers with other members must be transferred first.

## Stickers, GIFs and reactions
- Each server can have its own sticker pack ("Manage stickers" permission, 60 per server). Server stickers can be sent anywhere and show which server they come from.
- React with stickers (Annoy set and server packs).
- Favorite GIFs, saved on the Annoy account. The GIF tab has Favorites and GIPHY.

## Voice
- Right-click a stream to change its volume or open it in its own window.
- After a connection drop, the app rejoins the same voice channel.
- Saved microphone, output and camera stay selected when the system changes their IDs.

## Fixes
- Images in DMs open in the viewer instead of downloading.

## Also in this version
- Every remaining "distopic" identifier is now "annoy" (Linux app ID br.dev.geg.annoy; Windows updates still replace the same install).
- The News screen shows this version's changes.
