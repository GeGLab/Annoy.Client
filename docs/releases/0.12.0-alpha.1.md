# Annoy 0.12.0-alpha.1

## Store
- The hidden Integrations screen is now the **Store**, a fixed tab next to Servers. Its first tab is Integrations; more kinds of items will come as new tabs.
- Connect an integration to your Annoy account. When the service needs an API key, the key is encrypted in the app with your account key; the Annoy cloud cannot read it.
- Annoy's own integrations: **GPT** (OpenAI: text, images, recent history), **SteamProfiler** (`/steam profile`, `/steam versus`, profile card on your Annoy profile) and **VPNGo** (connect to chosen servers through a VPN profile).

## Integrations in DMs
- The composer's "+" now opens a menu: **Add integration** or **Attach file**.
- The other person must accept an integration before it works in the conversation. Either person calls it with `/command` or `@Name`.
- The call leaves the app of whoever added the integration, with that person's key, and only while that person is online. Answers show the integration's name and icon.

## Integrations on servers
- Server settings have an **Integrations** tab. The owner installs integrations from the Store and gives the API key, which stays on the server.
- New role permission **Use integrations**.

## VPNGo
- Each server connection can go through a VPNGo profile (needs VPNGo with `vpngo proxy` and Mihomo). A routed server never falls back to the usual network; its voice goes only through the VPN, over TCP.

## Connection
- When a server is online but needs a newer Annoy, the app shows **Update Annoy** instead of trying to reconnect, and links to the downloads when automatic updates are off or fail.

## Compatibility
- Integrations on servers need Annoy Server 0.12.0-alpha.1. Older servers keep working without the Integrations tab.
- The Store needs the devannoy service (devannoy.geg.dev.br).
